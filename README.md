# Uplift Modeling on Criteo Dataset

Проект по построению uplift-моделей для оценки эффекта рекламного воздействия на вероятность конверсии пользователя.

## Бизнес-задача

Определить, каким пользователям показывать рекламу, чтобы максимизировать прирост целевых действий (конверсий) при ограниченном бюджете.

## Данные

- Датасет: **Criteo Uplift v2.1**
- Объём: ~14 млн записей
- Признаки: `f0`–`f11`
- Treatment: бинарный флаг рекламного воздействия
- Target: `conversion`

## Реализованные модели

- **S-learner**
- **T-learner**
- **X-learner**
- **R-learner**
- Самодельный URF

## Метрика качества

**Qini-коэффициент** (площадь под Qini-кривой)

### Результаты

| Модель              | Qini-коэффициент |
|---------------------|------------------|
| R-learner           | **5897.5**       |
| X-learner           | 4313.8           |
| T-learner           | 1660.9           |
| URF (самодельный)   | 1660.9           |
| S-learner           | 1014.8           |

**Лучшая модель — R-learner.**
